# DemocracyBot
A Discord bot that runs a server and distributes power to an elected President every month. Made for the people of the nation of **Discordias**.

Built in Java using [JDA](https://github.com/DV8FromTheWorld/JDA) as a Gradle project.

![Our nation's glorious flag](https://github.com/FreshSupaSulley/DemocracyBot/assets/45902499/3278dc05-3fbc-414f-8717-b233af1c312b)

# Make your own server
Use the server template: https://discord.new/dGYCdUeTrpgb

# Updating
DemocracyBot utilizes GitHub Actions to update. To initiate an update, "the military" (me) needs to call `!update` in dbot DMs.
